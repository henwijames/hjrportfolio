# Workspace Customization Rules

- **No Rounded Corners (`rounded-none`)**: Never use rounded corners on layout cards, sections, buttons, or containers. Maintain a sharp, industrial exposed-grid aesthetic.
- **Exposed 1px Grid**: All layout sections must incorporate 1px grid boundaries (`border-neutral-200` / `border-neutral-800`) and 100vw divider breaks with `max-w-7xl border-x`.
- **Monospace Accents**: Use technical monospace fonts for metadata, status indicators, and section numbers.
