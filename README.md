# Henry James Ribano — Software Developer Portfolio

A modern, high-performance web portfolio built with **React**, **Vite**, **Tailwind CSS**, and **shadcn/ui**. The design follows a developer-centric **Exposed Grid Aesthetic** featuring structural 1px grid lines, full-bleed section dividers, and responsive layout architectures.

---

## 🎨 Design Aesthetic & Features

- **Exposed Grid System**: Precision 1px layout boundaries across viewports (`border-neutral-200` / `border-neutral-800`).
- **Full-Bleed Horizontal Divider Lines**: Viewport-wide (`100vw`) section breaks paired with centered container boundaries (`max-w-7xl`).
- **Technical Monospace Accent Labels**: Industrial/blueprint typography styling for section markers, status indicators, and system metadata.
- **Responsive Layouts**: Fully responsive side-by-side grids, full-height image containers, and sticky section headers.
- **Dark / Light Mode Support**: Built-in Tailwind color variables for seamless dark mode transitions.

---

## 🛠️ Tech Stack

- **Framework:** React (Vite)
- **Styling:** Tailwind CSS (v4)
- **UI Components:** shadcn/ui
- **Icons:** Lucide React / SVG
- **Package Manager:** `npm` / `pnpm`
